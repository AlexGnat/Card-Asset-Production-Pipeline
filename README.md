# Card-Asset-Production-Pipeline

Инструмент для АИ генерации коллекционных карточек
1. Цель: Автоматизированный пайплайн генерации и QA-валидации карточек под мобильные игры.

2. Стек: Python, Pollinations.ai (image-gen), OpenRouter
   
3. Среда разработки: Выполнено и тестировалось на https://www.kaggle.com

4. Инструкция по запуску:
1. Ключ API - откуда брать и куда прописывать

Ключ нужен один - от OpenRouter (он используется и для LLM-оркестратора, и для Vision QA, и для генерации картинок через openrouter-движок).

Зарегистрируйтесь / зайдите на openrouter.ai → Keys → создайте ключ (sk-or-v1-...).
В Kaggle-ноутбуке: Add-ons → Secrets (в правой панели ноутбука) → Add a new secret.
Label: OPENROUTER_API_KEY (имя должно совпадать буквально - код читает именно его: secrets.get_secret("OPENROUTER_API_KEY")).
Value: сам ключ.
Убедитесь, что secret привязан к этому конкретному ноутбуку (галочка Attach рядом с секретом) - иначе UserSecretsClient его не увидит и упадёт с ошибкой доступа.

В сам код ключ никуда руками не вписывается - config_cell_v18.py сам вытащит его в os.environ["VISION_API_KEY"] при запуске ячейки.
На ноутбуке должны быть включены интернет и Accelerator GPU T4 x2 (на правой панели в разделе Session options)
Учтите: с v17 генерация картинок платная (IMAGE_ENGINE="openrouter", ~$0.039/картинка), значит на вашем OpenRouter-аккаунте должен быть привязан способ оплаты / баланс - иначе получите ошибку авторизации именно на этапе картинок, а не на этапе текста.

3. Какой кнопкой запускать

Два разных режима, выбирайте по ситуации:

Работаете интерактивно, хотите видеть логи по ходу дела - запускайте ячейки по одной кнопкой ▶ слева от ячейки (или Shift+Enter), сверху вниз, в порядке из таблицы. Это обычный интерактивный (Edit) сеанс.
Хотите зафиксировать результат и быть уверены, что прогресс не потеряется при закрытии вкладки - кнопка Save Version (верхний правый угол) → выбрать Save & Run All (with outputs). Это гарантированно коммитит /kaggle/working как есть после полного прогона.

Важно: интерактивная сессия (просто открытая вкладка с ▶) не переживает закрытие/протухание сессии без явного Save Version - это было подтверждено на практике (см. ниже про resume).

4. Как продолжить прерванную работу

Есть два принципиально разных случая:

A. Ядро (kernel) перезапустилось, но вы в той же вкладке/сессии.
Просто заново выполните ячейки 1→2→3→4 по порядку. Пайплайн сам подхватит прогресс:

Stage 1 (концепты вариантов) резюмируется через SET_VARIANTS_EXPORT_JSON_PATH - те же варианты не генерируются заново.
Stage 2 (сам рендер картинок) резюмируется через EXPORT_JSON_PATH - уже готовые (Ready) карты не рендерятся повторно.

B. Вы закрыли вкладку/ноутбук и открыли его через день (новая сессия).
Это на практике теряет прогресс полностью - если между сессиями не было Save Version → Save & Run All (with outputs), повторный вызов render_set_variants("Кино коллекция") сгенерирует совершенно новые случайные варианты вместо продолжения прежних. Поэтому либо:

держите один и тот же kernel живым до полного завершения задачи, либо
делайте Save Version → Save & Run All (with outputs) после каждого крупного этапа.

Перед финальным чистым прогоном (сейчас у вас именно этот случай - код только что дошёл до v32, а до этого копился прогресс на несовместимых по коду версиях) - обязательно почистите старые артефакты, иначе новые Ready-карты будут перемешаны со «старыми сиротами»:

python
import shutil, os

for path in (READY_OUTPUT_DIR, OUTPUT_DIR):
    shutil.rmtree(path, ignore_errors=True)
    os.makedirs(path, exist_ok=True)
for path in (EXPORT_JSON_PATH, SET_VARIANTS_EXPORT_JSON_PATH):
    if os.path.exists(path):
        os.remove(path)

Запускайте это отдельной ячейкой после ячейки 1 (конфиг), но до ячейки 4 (запуск).
